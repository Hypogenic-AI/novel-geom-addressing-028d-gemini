# Downloaded Datasets

This directory contains datasets for the research project. Data files are NOT committed to git due to size. Follow the download instructions below.

## Dataset 1: KiloGram

### Overview
- **Source**: https://github.com/lil-lab/kilogram
- **Size**: >1,000 stimuli
- **Format**: JSON, SVG
- **Task**: Visual reasoning, part-level segmentation
- **Notes**: Contains rich verbal descriptions and precise SVG coordinates.

### Download Instructions
The dataset was cloned from GitHub into `code/kilogram/dataset`.
For use in experiments, point to `code/kilogram/dataset/tangrams-svg/` for geometries and `code/kilogram/dataset/dense.json` for labels.

## Dataset 2: Tangram

### Overview
- **Source**: https://github.com/yizhouzhao/Tangram
- **Size**: ~700 items
- **Format**: Images, JSON
- **Task**: Shape replication
- **Notes**: Focuses on human experience in solving tangram puzzles.

### Download Instructions
The dataset was cloned from GitHub into `code/Tangram/`.
